SystemDevtools

Support for the iPad and iPhone app

SystemDevtools shows live system stats from your Linux servers over SSH. Nothing needs to be installed on the server.

What a server needs

An SSH server with public-key or password login, a user account, a standard sh, and readable /proc and /sys, which is the default. For GPU stats, the NVIDIA driver's nvidia-smi.

Adding a server

Tap +, enter the address and username, and choose a key. The app can create a key in your device's Secure Enclave. Copy its public key line into ~/.ssh/authorized_keys on the server. You can also import an Ed25519 or ECDSA key, or use a password. RSA keys aren't supported, so add an Ed25519 key if your server accepts only RSA.

Troubleshooting

  • Host key changed: the app pins each server's host key on first connect and refuses a different one. If you rebuilt the server on purpose, delete its record and add it again.
  • Values show as unavailable: some values, such as CPU package power and other users' disk I/O, are readable only by root on Linux. The app shows them as unavailable instead of zero.
  • Process actions: terminate, kill, signals, and renice work on processes your SSH user owns, or on any process when sudo is set up.
